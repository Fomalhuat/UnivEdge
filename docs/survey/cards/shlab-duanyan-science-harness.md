## 机制提取

### ① 任务分解与角色架构

四层产品体系：底层科学模型（书生-S2）+ 物理世界模型（书生-W0）→ 中间层 **Science Harness** + 可信科研证据链 + 真实实验验证 → 领域层（专业模型 / 数据集 / 方法 / **Skill**）→ 用户层（云端 Web 工作台 + 本地桌面工作台）。

核心分工（原文）：

> "长程：**模型动脑，Harness动手**"
>
> "模型侧负责科学推理、假设生成、策略判断与知识组织；**Science Harness 侧负责研究状态保持、跨轮次上下文管理、异构资源编排、多角色协同、实验反馈接收与任务重规划**。"

### ② 验证/审查机制

证据链三环节：**交付对齐 → 独立核验 → 执行复现**。

> "平台将文献、数据、代码、工具调用、计算结果与实验记录，组织为一条完整证据链，让研究过程从输入到输出的关键环节相互关联、有迹可循。在证据链之上，平台引入**评审智能体**，对AI生成的研究结果进行独立核验，围绕**需求完成度、正确性、证据与来源、可复现性、产物质量、工具执行、历史审查**七个维度逐维独立核验。核验结果按结论分级输出，让每一条结论的质量状态清晰可见。"

执行复现：

> "平台完整保留关键参数、工具版本、实验条件与执行日志，支持在相同条件下复跑，并依据完整过程记录对结果进行复核。"

### ③ 上下文/记忆策略

> "当新的计算结果、实验数据或专家意见进入系统后，Science Harness将其写入当前研究状态，模型据此重新评估假设、调整策略并生成下一轮任务。"

> "研究过程中形成的**有效路径、失败记录和关键决策也被持续沉淀**，避免任务因上下文中断而反复从头开始。"

### ④ 人工介入点

发布稿未给出显式门控清单（无"何时必须人批准"的规则）。人类以"专家意见"形式作为**新证据**进入研究状态；另有"科研 Token Plan"作为资源计量。

### ⑤ 成本/规模数据

- 六大领域落地；蛋白质、新材料完成**干湿实验闭环**；
- 联合上海同步辐射光源、中国散裂中子源、原子制造大装置、电合成新技术研究所，把闭环延伸到大科学装置与中试平台；
- Token Plan 按 Token 计费（每位用户每月免费额度，未公开单价）。

### ⑥ 失败模式与自述局限

发布稿性质，**未自述局限**。但平台自设三问，本身即其承认的难点：

> "①面对复杂、长期的科研任务，AI如何保持研究状态并持续推进？②面对模型生成的结果，如何核查证据、复核过程并复现结论？③面对真实科学问题，如何将计算方案送入实验系统？"

| 6 | 审查性价比分级 | **两端皆无**：端砚以 Token Plan 计量资源，但未见"审查档位/成本"规则——与 `docs/17` "无人把审查性价比当核心问题"结论一致 |

**可移植性判定**：
- "历史审查"维度 → **内核**（§5.1 输入包 + 一条 RC 检查项，成本低）；
- 跨产物证据链 → **领域资产 / 产物存储**（成本中，形态待定）；
- 真实实验/大科学装置/W0 → **不适用**（UnivEdge 无执行权、无实验室，同 coscientist 处置）。
