## 1. 通用数学/数值约定

### 1.1 球谐函数负 m 约定（Condon-Shortley）｜#球谐 #约定高风险

- **约定**：标准 Condon-Shortley 相位，满足恒等式：
  ```
  Y_{l,−m}(θ,φ) = (−1)^m · Y*_{l,m}(θ,φ)
  ```
- **验证恒等式**（自检方法）：
  1. 对任意 (l, m)，数值计算两侧，残差应为 0（1e-14 量级）；
  2. 实函数的球谐系数必须满足 a_{l,−m} = (−1)^m · a*_{l,m}——用此约束检查外部数据是否采用同一约定；
  3. 连带勒让德：P_l^{−m} = (−1)^m · (l−m)!/(l+m)! · P_l^m（scipy.special.lpmv 负阶遵循此式）。
- **踩坑记录**：2026-08-13 Step 4B/4C——Ylm 负 m 实现漏 (−1)^m 相位，导致 ΦS_{l,−m} 恢复规则错误（自洽但错，被外部 ret 数据对账暴露）。
- **来源**：MathWorld / 教科书标准约定；本仓库 run/step4b 验证。

### 1.2 sympy wigner_d 矩阵约定（转置陷阱）｜#符号计算 #约定高风险

- **约定**：`sympy.physics.wigner.wigner_d(l, α, β, γ)` 返回的矩阵元素约定为：
  ```
  D[i][j] = d^l_{j−l, i−l}(β)   （即标准小 d 矩阵的转置 + 相位）
  ```
  直接按"行=第一指标"读取会取反指标顺序，导致错误归零（l 奇 m 奇模）。
- **验证恒等式**：与标准小 d 矩阵数值对照（如 d^1(π/2) 已知矩阵 [[0.5,−0.7071,0.5],[0.7071,0,−0.7071],[0.5,0.7071,0.5]]），确认索引方向。
- **踩坑记录**：2026-08-13 Step 4B——Wigner D 解析路径因约定误读而错误，最终**弃用解析路径，改用双独立数值路线交叉验证**（教训：约定不确定时，数值交叉验证为权威，解析只做锚点）。
- **来源**：sympy 文档 + 实测；本仓库 run/step4b。

### 1.3 二维积分端点奇点处理（u 变量替换）｜#数值方法

- **约定/技巧**：含 1/√(1−cosΘ) 型端点奇点的积分，用变量替换 u = 1−cosΘ 消去：
  ```
  ∫₀^π (1−cosΘ)^{−1/2} f(cosΘ) sinΘ dΘ = ∫₀² u^{−1/2} f(1−u) du
  ```
  端点奇点变为 u^{−1/2}（可积、数值稳定）。
- **验证恒等式**：基元积分 ∫₀^π (1−cosΘ)^{−1/2} P_l(cosΘ) sinΘ dΘ = 2√2/(2l+1)。
- **踩坑记录**：2026-08-13 Step 4B——nquad 直积在高 l（l≥19）端点 roundoff → NaN；u 替换后稳定到 1e-12。
- **来源**：本仓库 run/step4b（integrate.py）。

## 2. 单位制与符号约定（按领域填充）

### 2.1 自然单位制声明规范｜#通用

- **约定**：采用约定单位制时（如自然单位制 G=c=1，G 为引力常数、c 为光速），必须在假设清单中**显式声明**；量纲检查按声明单位制执行。
- **验证恒等式**：两端量纲一致（或同属声明单位制下的无量纲量）。
- **来源**：METHODOLOGY §2.4 PC-01。

### 2.2 GR/引力领域

#### 2.2.1 THZ 坐标角色（计算坐标 = 标准 Schwarzschild）｜#GR #坐标

- **约定**：代码全程在标准 Schwarzschild 坐标 {t,r,θ,φ} 下运行；THZ 坐标（PRD67 App.B 的 x̄,ȳ,z̄）
  仅用于**构造奇异场距离 ρ̃**（4 阶局部惯性系坐标变换，保证 1/ρ̃ 的 4 阶展开结构）；
  x̄,ȳ,z̄ 是 (r,θ,φ) 的函数，代入后 Seff 为纯 Schwarzschild 坐标函数，无 THZ 坐标残留。
- **验证恒等式**：演化网格（tor2sch/sch2tor）、势 V_l=f·[l(l+1)/r²+2M/r³]、提取 dPhi_r、
  mode-sum 球谐全部为 Schwarzschild 量；PRD77 tex line 342 "We work in Schwarzschild coordinates"。
- **踩坑记录**：litcheck01 V1（2026-08-17 确认）——曾担心轨道演化文献坐标与计算坐标需映射；
  核实后确认天然一致，界面无需坐标变换。
- **来源**：THZ 坐标说明报告（2026-08-17）+ sympy_gen_c.py / thz_source.hpp / ef_fem_evolution.hpp 核实。

#### 2.2.2 标量自力符号（取负约定；符号正确性已验证）｜#GR #符号

- **约定**：数值场 = −物理场（取负约定），**最终输出反号为物理值**。v1.0 的 F_Y = ∂_rψ^R = **+1.3782844e-5**。
- **符号验证（2026-08-19 通过，v2symbol）**：耗散通道 `dE/dt = −q·∂_tψ^R/u^t = −3.14e-5 < 0`（能量减少）。
  证据链（不依赖推测，完全独立）：
  1. 代数推导（SymPy）：dE/dτ = −q∂_tψ^R（u_t u^μ 项精确抵消，无近似）
  2. PRD77 原文：∂_tψ^R "equivalent to the rate of energy lost by radiation"
  3. PRD77 频域锚点：∂_tψ^R = +3.7501e-5（TD）vs +3.750227e-5（FD），0.000431%——**正号确定**
  4. r⁻⁴ 标度律：dE/dt(10M)/dE/dt(12M) = 2.0735 vs 理论 2.0736 完美匹配
  5. 量级：与弱场 Larmor (2/3)q²a² 同量级
- **历史**：曾为推测（反射机制，2026-08-17）→ 撤回为待验证（2026-08-18）→ 独立验证通过（2026-08-19）。
- **验证恒等式**：∂_tψ^R 与 PRD89 频域一致（0.0021%）；与导师逐位一致（12 位有效数字）。
- **注意**：波区通量（通量平衡法）需"substantial number of orbits"演化才稳定（PRD77 原文），
  短演化下慢瞬态污染使通量虚高（v2symbol 实测 12 倍）——长时验证用 T3200+ 或吸收边界。
- **来源**：v2symbol 报告（2026-08-19）+ PRD77 原文 line 990-1000 + benchmarks B1/B6。

#### 2.2.3 标量电荷运动方程（三方交叉验证）｜#GR #运动方程

- **约定**（标准形式，PPV 2011 Eq (1.36)(1.37) / Quinn 2000 / PRL 2012 Eq (2)(3) 独立来源一致）：
  ```
  □ψ^R = Seff(x, z(τ), u(τ))                 # 场方程（有效源，依赖粒子位置/速度）
  Du^α/dτ = (q/m)(g^αβ + u^αu^β)∇_βψ^R      # 运动方程（投影到 u 正交）
  dm/dτ = −q u^α∇_αψ^R                       # 质量方程（标量场零自旋特有，不可省略）
  ```
- **验证恒等式**：三方来源公式逐项对照一致（Quinn 公理化推导 / PPV 综述 §1.8 / PRL 自洽实现）；
  PRL 2012 数值（p0=7.2, e0=0.5, q=1/8..1/64）可作数值对照锚点。
- **来源**：litcheck01 文献核对（2026-08-18）+ PRL 108.191102 核对记录（领域资产，本地维护）。
