# 主张注册表（Claims）

> 记录系统：agent 产出的主张及其状态机（claimed → verified → rejected），METHODOLOGY §0.3 的落点。
> 原则：主张必须可溯源（证据 = 锚点/产物路径）；状态变更显式记录（claimed 是常态，verified 需要锚点，rejected 说明理由）。
> 关联：knowledge/benchmarks.md（verified 主张的数值证据）、review-lessons.md（rejected 教训）、VERIFICATION NC-01/NC-06。

## 状态定义

- **claimed**：已提出，未锚定到独立参照——不能当作已验证事实使用；
- **verified**：锚定到独立参照（外部锚点/双路线交叉），偏差在判据内；
- **rejected**：被独立证据否定，保留记录（教训）。

## 使用约定

- 新主张默认 **claimed**；升级为 verified 必须给出锚点（外部优先）；被否定即 rejected 并记录理由；
- 状态变更时更新日期与证据，不静默覆盖（保持历史可追溯）；
- 使用 claimed 主张时须附"待验证点"——违反视为 B1（无依据断言）。
